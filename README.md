# 🎯 Quiz Battle

A colorful **single-player General Knowledge Quiz Game** with an adventure-style level map.

Quiz Battle lets players answer GK questions, earn points and stars, unlock new levels, and play quizzes in multiple languages.

## ✨ Features

* 🎮 Single-player quiz game
* 🧠 General Knowledge questions
* 🗺️ Adventure-style level map
* 🔓 Level unlock system
* ⭐ Stars and rewards
* 🔥 Streak and scoring system
* ⏱️ Countdown timer
* 💡 Hint and 50/50 power-ups
* 🔄 Play Again option for the same level
* ⬅️ Back navigation button
* 🏆 Achievements and leaderboard
* 👤 Player profile and avatar
* 🌐 Multiple quiz languages
* 💾 Save player progress

## 🌍 Quiz Languages

The **game interface is always in English**, while quiz questions and answers can be available in:

* English
* Tamil
* Hindi
* Telugu
* Malayalam
* Kannada
* Bengali
* Marathi

## 🎮 How to Play

1. Create your player profile.
2. Select your quiz language.
3. Start from Level 1.
4. Answer the GK questions.
5. Earn points and stars.
6. Complete the level to unlock the next level.
7. Use power-ups when needed.
8. Choose **Play Again** to replay the same level with new questions.
9. Progress through the map and become the **GK Master**.

## 🗺️ Level System

```text
Level 1 → Level 2 → Level 3 → Level 4 → Level 5
                              ↓
                         Boss Quiz
```

Higher levels contain more challenging questions.
